## CQ13. Which unread works are recommended to a reader, and why?

**SPARQL features:** CONSTRUCT  
**Ontology path:** `CQ12's path; the CONSTRUCT keeps the supporting triples as the explanation`  
**Result:** HTTP 200, 20 triples (expected 20) PASS
  
*Returns an explanation subgraph; agent.py ranks it by confidenceScore. The candidate work is selected with the property alternation ?e (:fromWork|:toWork) ?w rather than { BIND(?from AS ?w) } UNION { BIND(?to AS ?w) }. The BIND form works in RDFLib but returns nothing in Fuseki: a variable bound inside a UNION branch is out of scope for a later FILTER NOT EXISTS, and Fuseki applies that scoping rule strictly. See REPORT.md section 6.7.*

```sparql

PREFIX owl:  <http://www.w3.org/2002/07/owl#>
PREFIX xsd:  <http://www.w3.org/2001/XMLSchema#>

CONSTRUCT {
  ?reader :hasInterestIn ?c .
  ?e a :Engagement ; :fromWork ?from ; :toWork ?to ;
     :aboutConcept ?c ; :stance ?stance ; :confidenceScore ?conf .
  ?w :title ?title ; :createdBy ?author .
  ?author rdfs:label ?authorName .
}
WHERE {
  VALUES ?reader { :reader1 }
  ?reader :hasInterestIn ?c .
  ?e a :Engagement ; :aboutConcept ?c ; :fromWork ?from ; :toWork ?to ;
     :stance ?stance ; :confidenceScore ?conf .
  ?e (:fromWork|:toWork) ?w .
  ?w :title ?title ; :createdBy ?author .
  ?author rdfs:label ?authorName .
  FILTER NOT EXISTS { ?reader :hasRead ?w }
```
